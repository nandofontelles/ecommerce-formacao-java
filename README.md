# ecommerce-formacao-java
Aplicação de E-Commerce desenvolvido com Java 21 e Spring Boot para o curso da Full Stack Club

## Tecnologias
- **Backend**: Spring Boot, Spring MVC, Spring Data JPA, Hibernate, Docker, Postgres
- **Frontend**: Thymeleaf, HTML5, CSS3, JavaScript
- **Database**: Postgres
- **Build**: Maven

## Requisitos
- Java 21
- Maven 3.6+
- Docker Desktop
